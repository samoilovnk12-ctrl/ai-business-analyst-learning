# Архив

Архив сохраняет прежние версии курса, чтобы ни одна полезная идея не исчезла во время перепроектирования.

## `legacy-course-v2/`

Здесь находятся старая 26-недельная архитектура, туристическая версия «Меридиана», прежняя дизайн-система, первый месяц и старый конспект.

Эти документы:

- не являются текущей программой;
- не должны использоваться без сверки с `LEARNING-CONTEXT.md`;
- могут служить источником отдельных идей и историей принятых решений;
- удаляются только после отдельной проверки переноса ценных частей.
