# Пилот

Здесь хранится первый совместно проектируемый модуль. Он нужен для проверки понятности, интереса, длительности и переноса навыков до масштабирования курса.

Текущие файлы относятся к пилоту, созданному до полного перепроектирования интерфейса. Содержание сохраняется как вход, но способ показа будет пересмотрен.
