# Чатовый сеанс 1 — «Что на самом деле делает бизнес-аналитик»

Статус: **начат 5 сентября 2026 года**.  
Этап: **P0 — вход в профессию и безопасный старт**.  
Плановое активное время: **80–100 минут**, три части по 25–35 минут.  
Канал: **живой диалог в текущем чате Codex**.

## Рабочий результат

К концу сеанса ученик должен на новом примере своими словами:

1. объяснить, за какой результат отвечает бизнес-аналитик;
2. отличить работу аналитика от работы руководителя, системного аналитика и разработчика;
3. пройти путь `поручение → проверенная картина → варианты изменения → проверка результата`;
4. составить короткий и безопасный план первых действий стажёра;
5. не обещать решение до проверки фактов, полномочий и ограничений.

## Источниковая основа

- MAP-01 из `program/SOURCE-TO-LEARNING-MAP.md`.
- SRC-0006: реальные начальные обязанности стажёра Яндекс 360.
- SRC-0007 и SRC-0070: ширина роли, гибридные вакансии и требования российского рынка.
- IIBA Business Analysis Standard/Core Standard: профессиональный цикл анализа потребности, изменения и ценности.
- Уже подтверждённые записи ученика 0002–0005 используются для адаптации, но не заменяют новый перенос.

## Части занятия

### Часть 1. Понять профессию

- Рабочее событие первого дня в «Меридиане».
- Простая модель полного цикла работы аналитика.
- Разница между ответственностью аналитика и соседних ролей.
- Разобранный пример из другого бизнеса.
- Первая самостоятельная попытка на новом кейсе.

### Часть 2. Разобрать поручение

- Ответ ученика разбирается по смыслу, а не по совпадению с шаблоном.
- При необходимости используется лестница H0–H5.
- Ученик последовательно определяет решение руководителя, известные факты, неизвестное, участников и безопасный первый шаг.
- Формируется рабочая карточка поручения.

### Часть 3. Перенести навык

- Новая ситуация из другой отрасли без подсказанного решения.
- Ученик объясняет границы своей роли и выбирает следующий шаг.
- Короткое возвращение к теории без просмотра готового ответа.
- В конспект и learning record попадает только то, что подтверждено самостоятельным действием.

## Правила ведения

- Ученик отвечает обычными словами и может рассуждать вслух.
- Преподаватель не перечисляет ответ внутри вопроса.
- После каждого ответа выбирается только один ближайший шаг.
- Формальная сборка ответа по профессиональной структуре выполняется после слова `готово`.
- Если термин непонятен, практика останавливается и термин объясняется на бытовом примере.
- Сеанс можно прервать после любой из трёх частей; точка продолжения сохраняется.

## Текущая точка

Начата часть 1. Следующее действие — ответ ученика на первое рабочее поручение после вводного объяснения роли.
