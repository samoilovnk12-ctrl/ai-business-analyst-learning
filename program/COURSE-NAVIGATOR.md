## Как читать прогресс

Пройденный разговор не равен освоенному навыку.

| Состояние | Что оно означает |
|---|---|
| Не начато | тема ещё не объяснялась |
| Объясняется | формируется понимание |
| С помощью | действие выполнено после подсказки |
| Самостоятельно | выполнено без содержательной подсказки |
| Подтверждено | навык перенесён на новый случай |
| Повторить | после паузы или ошибки нужна новая проверка |
| В портфолио | результат проверен и обезличен |

## Ближайшее решение

Согласовать архитектуру обучения через чат и затем вместе спроектировать первый чатовый сеанс P0. Не переносить автоматически слабое содержание HTML-пилота и не создавать десятки уроков до проверки нового формата.
