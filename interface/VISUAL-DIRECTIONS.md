# Визуальные направления оболочки «Меридиан»

Статус: **три направления подготовлены для выбора**  
Этап: **UI-05**  
Дата: **4 сентября 2026 года**

## Общая неизменяемая основа

Все три варианта сохраняют принятые решения:

- метафора рабочего компьютера Windows 11;
- тёмно-синий каркас, бирюзовый акцент и светлые рабочие окна;
- отдельные приложения и перемещаемые окна;
- один ближайший шаг без скрытия всей программы;
- постепенное открытие приложений;
- отдельная панель обучения и переход к Codex-помощнику;
- спокойный фон, простые иллюстрированные сотрудники и отсутствие звуков;
- масштабирование от Стажёра к Junior и Middle.

## Направление A — «Спокойный проводник»

### Идея

Начальный экран максимально понятный. В центре находится одно главное окно текущей работы; остальные приложения доступны через панель задач и небольшую боковую полку. Панель обучения всегда видна справа, но может быть свёрнута.

```text
┌──────────────────────────────────────────────────────────────┐
│ проект / сюжетное время / уведомления                        │
├───────┬──────────────────────────────────────┬───────────────┤
│ apps  │ одно главное рабочее окно            │ обучение      │
│       │                                      │ следующий шаг │
│       │                                      │ помощь        │
├───────┴──────────────────────────────────────┴───────────────┤
│                      панель задач                            │
└──────────────────────────────────────────────────────────────┘
```

**Подходит:** первые недели уровня «Стажёр», тревога перед незнакомым интерфейсом, обучение с ведением.  
**Риск:** при долгом использовании может казаться слишком учебным.  
**Фирменный элемент:** «нить маршрута» — тонкая линия связывает сообщение, задачу, материал и результат.

## Направление B — «Живой рабочий стол»

### Идея

Самое близкое к настоящему компьютеру. На фоне лежат ярлыки и виджеты, окна перекрываются, перемещаются и сворачиваются. Учебная панель открывается как самостоятельное приложение. Пользователь сильнее ощущает, что вышел на работу.

```text
┌──────────────────────────────────────────────────────────────┐
│ ярлыки       окно сообщения                                  │
│              ┌───────────────────┐                           │
│              │      окно         │  окно задачи              │
│   виджет     └───────────────────┘  ┌────────────────────┐   │
│   проекта                           └────────────────────┘   │
├──────────────────────────────────────────────────────────────┤
│              центрированная панель задач                    │
└──────────────────────────────────────────────────────────────┘
```

**Подходит:** основной режим после знакомства с приложениями, реалистичные рабочие события, исследование среды.  
**Риск:** новичок может потеряться среди окон. Это компенсируется командой «Вернуться к работе» и подсветкой нужного окна.  
**Фирменный элемент:** фон меняется по клиентскому проекту и незаметно показывает его отрасль.

## Направление C — «Операционный центр»

### Идея

Более профессиональный и информационно плотный режим. Слева — поток событий рабочего дня, в центре — выбранный объект, справа — состояние проекта, доказательства и риски. Это не дашборд ради цифр: панели показывают, почему задача требует внимания.

```text
┌──────────────────────────────────────────────────────────────┐
│ проект / команда / поиск / помощник                          │
├─────────────┬─────────────────────────────┬──────────────────┤
│ события дня │ выбранная задача или данные │ факты и риски    │
│ 09:20       │                             │ что проверить    │
│ 10:00       │                             │ следующий шаг    │
├─────────────┴─────────────────────────────┴──────────────────┤
│ приложения / открытые объекты / состояние синхронизации     │
└──────────────────────────────────────────────────────────────┘
```

**Подходит:** Junior и Middle, сложные проекты, несколько параллельных источников информации.  
**Риск:** слишком высокая плотность для старта с нуля.  
**Фирменный элемент:** «лента доказательств» отделяет факты, слова людей и гипотезы.

## Предварительное решение дизайнера

Не выбирать один вариант для всех уровней. Рекомендуемая система:

1. начать со «Спокойного проводника»;
2. постепенно разрешить свободный «Живой рабочий стол»;
3. открыть «Операционный центр» как профессиональный режим на сложных проектах;
4. оставить пользователю возможность вернуться к более простому представлению.

Так визуальное развитие станет частью профессионального роста, а не декоративной сменой темы.

## Самопроверка против шаблонного дизайна

- Убраны рекламный hero-блок, абстрактные статистические карточки и декоративные градиенты.
- Бирюзовый используется для направления внимания и состояния, а не для украшения каждой панели.
- Варианты отличаются пространственной логикой, а не только цветом.
- Рабочие термины заменены понятными действиями там, где ученик ещё не знаком с инструментом.
- Каждое направление сохраняет реальное содержание первого рабочего эпизода, а не демонстрационный lorem ipsum.
