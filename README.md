# Бизнес-аналитик по внедрению ИИ

Персональная учебная программа до 1 марта 2027 года. Цель — подготовиться к работе бизнес-аналитиком по внедрению ИИ и собрать практическое портфолио.

## Быстрый старт

1. Откройте опубликованный учебный сайт.
2. Перейдите к текущему уроку.
3. Выполните практическое задание.
4. Отправьте ответ преподавателю в чате Codex.
5. После проверки попросите: `Заверши учебную сессию, сохрани контекст и прогресс, затем отправь изменения на GitHub.`

## Как продолжить в новом чате

Откройте этот репозиторий в Codex и напишите:

```text
$teach Продолжи мою программу. Сначала прочитай MISSION.md, NOTES.md,
LEARNING-CONTEXT.md, RESOURCES.md, последний файл в sessions/ и все
learning-records. Затем кратко напомни, где мы остановились, и предложи
следующее действие. Ничего не считай освоенным без доказательства.
```

## Где хранится память

- `MISSION.md` — долгосрочная цель.
- `NOTES.md` — предпочтения и правила преподавания.
- `LEARNING-CONTEXT.md` — текущее состояние курса и инструкция продолжения.
- `sessions/` — краткие итоги каждого учебного чата.
- `learning-records/` — только подтверждённые знания и навыки.
- `lessons/` — интерактивные уроки.
- `reference/` — справочники и карта программы.
- `RESOURCES.md` — проверенные источники.

## Важное ограничение

Репозиторий сохраняет содержательный контекст обучения, но не является автоматическим архивом полного текста сообщений Codex. Полную историю задачи можно читать в самом Codex, если она доступна в аккаунте. Для независимости от конкретного чата после каждой сессии создаётся структурированный итог в `sessions/`.

Никогда не добавляйте в репозиторий персональные данные клиентов, внутренние документы, коммерческие секреты, API-ключи и пароли. Репозиторий публичный.
