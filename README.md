## Текущее состояние

Сейчас содержательная архитектура уровня «Стажёр» и требования к новому интерфейсу зафиксированы. Идёт сравнительный аудит образовательных платформ и рабочих систем. Старый интерфейс сохранён временно и не считается утверждённой версией.

## Основные разделы

- [`governance/`](governance/) — решения, правила управления и трекеры.
- [`program/`](program/) — архитектура обучения, оценивание, практика и пилот.
- [`simulation/`](simulation/) — компания «Меридиан», персонажи, клиенты и кейсы.
- [`interface/`](interface/) — новый интерфейс, Miro и ход перепроектирования.
- [`research/`](research/) — реестр, карточки и подробные заметки по источникам.
- [`competencies/`](competencies/) — обязательная карта знаний уровня «Стажёр».
- [`learning-records/`](learning-records/) — только подтверждённые знания ученика.
- [`sessions/`](sessions/) — история завершённых учебных сессий.
- [`archive/`](archive/) — старые версии, сохранённые только для истории и возможного переиспользования.
