# Временное рабочее пространство

Здесь находятся распакованные книги, OCR, транскрипты, скачанные копии для проверки и другие промежуточные материалы.

- Содержимое папки не публикуется и игнорируется Git.
- Важные выводы обязательно переносятся в `research/`.
- `source-review/` содержит материалы глубокой проверки источников.
- `unrelated-assets/` содержит сохранённые файлы, которые не относятся к курсу.

Удалять временные материалы можно только после проверки, что соответствующие карточки и заметки в `research/` завершены.
