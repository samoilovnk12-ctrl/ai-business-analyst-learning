# SRC-0059 — Присланные SQL-тренажёры и шпаргалки

## Источники и честный статус

### LeetCode SQL 50

- [Top SQL 50](https://leetcode.com/studyplan/top-sql-50/) — англоязычный план из 50 задач.
- Официальный API плана проверен 2 сентября 2026 года: все 50 задач помечены бесплатными.
- Семь групп: `SELECT` (5), базовые `JOIN` (9), агрегаты (8), сортировка/группировка (7), усложнённые `SELECT`/`JOIN` (7), подзапросы (7), строки/регулярные выражения/особые клаузы (7).
- Сложность: 33 easy, 16 medium, 1 hard.
- **Статус:** полный список и метаданные `structurally-reviewed`; решения ещё не выполнены.
- **Роль:** дополнительная практика и подготовка к технической части собеседования после основ. Не учебник с нуля.

### Tproger

- [«Основные команды SQL: шпаргалка»](https://tproger.ru/translations/sql-recap).
- Текст полностью доступен и прочитан. Примеры — MySQL.
- Темы: база/таблицы и ограничения; `INSERT`, `UPDATE`, `DELETE`; `SELECT`, `DISTINCT`, `WHERE`, логика, `IN`, `JOIN`, `GROUP BY`, `HAVING`, агрегаты и вложенные запросы.
- **Роль:** русская шпаргалка для повторения, не контролирующий первоисточник.

### Habr

- [«Как изучить SQL за ночь, или шпаргалка для системного аналитика»](https://habr.com/ru/articles/664550/), 2022, обновлена в 2023.
- Текст полностью доступен и прочитан. Пример предметной области «сладости» объясняет схему, DDL/DML, `SELECT`, условия, группировку, сортировку, объединения и агрегаты.
- **Ограничение:** формула «за ночь» — заголовок, а не реалистичный срок формирования навыка. Правильно использовать как русскую вводную шпаргалку.

### SQL-EX

- [«Упражнения по SQL»](https://www.sql-ex.ru/?Lang=0) — бесплатный русский тренажёр, сертификаты добровольны.
- На дату проверки сайт заявляет 152 учебных и 240 рейтинговых задачи `SELECT`, а также 68 упражнений по `INSERT`, `UPDATE`, `DELETE`, `MERGE`; есть справка, тесты и моделирование.
- Основная реализация — SQL Server; на сайте есть выбор СУБД для части учебных задач.
- **Роль:** большой дополнительный банк практики. Старый интерфейс и диалект SQL Server требуют отдельного пояснения.

## Общий вывод

Присланные материалы полезны, но решают разные задачи. Tproger и Habr — объяснение/повторение; LeetCode и SQL-EX — банки задач. Они не заменяют связный курс и профессиональную проверку корректности запроса.
