# SRC-0071 — Нормативное ядро UML

Основной источник: [OMG UML 2.5.1](https://www.omg.org/spec/UML/), формальная спецификация. Она отделяет структурное моделирование от поведения и описывает, среди прочего, class, component, deployment, activity, state machine, sequence и use case concepts.

Для стажёра нужен не весь метамодельный стандарт, а четыре рабочих выбора:

- use case — цели внешних акторов и граница системы;
- activity — поток действий и решений;
- sequence — обмен сообщениями во времени;
- class — понятия предметной области, атрибуты и связи.

PlantUML из SRC-0065 — способ записывать схемы текстом, а не отдельная методология. Качество модели проверяется вопросом, аудиторией, корректной семантикой и тем, помогает ли она принять решение. Статус: `official core reviewed`, `approved for intern scope`.
