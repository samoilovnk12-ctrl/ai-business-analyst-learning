# Исследование источников

Полная доказательная база программы.

## Начать здесь

- [`SOURCE-REGISTER.md`](SOURCE-REGISTER.md) — общий реестр.
- [`INTERN-SOURCE-COVERAGE.md`](INTERN-SOURCE-COVERAGE.md) — покрытие тем уровня «Стажёр».
- [`INTERN-SOURCE-INTAKE.md`](INTERN-SOURCE-INTAKE.md) — входящие материалы пользователя.
- [`SOURCE-COVERAGE-PROTOCOL.md`](SOURCE-COVERAGE-PROTOCOL.md) — правила честной проверки.
- [`COURSE-INTERFACE-EXPERIENCE-AUDIT.md`](COURSE-INTERFACE-EXPERIENCE-AUDIT.md) — сравнение семи образовательных платформ.
- [`WORKSPACE-SYSTEMS-EXPERIENCE-AUDIT.md`](WORKSPACE-SYSTEMS-EXPERIENCE-AUDIT.md) — рабочие модели Jira, Teams, Confluence, Excel и Miro.
- [`source-cards/`](source-cards/) — роль, качество и статус каждого источника.
- [`source-notes/`](source-notes/) — подробные аналитические заметки.

Папка `tmp/` может содержать распакованный текст, OCR и транскрипты, но источником учебных решений считаются только проверенные документы из `research/`.
