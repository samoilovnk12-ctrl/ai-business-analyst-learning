# Пакет источников по критическому мышлению — 0001

Дата регистрации: 2026-08-31.

## Состав пакета

| ID | Источник | Текущий статус | Основной риск |
|---|---|---|---|
| SRC-0008 | Максим Дорофеев, «Джедайские техники» | структура обнаружена, полного законного чтения пока нет | присланный PDF имеет неподтверждённое происхождение |
| SRC-0009 | Видео «5 правил продуктивного дня» | полностью просмотрено по субтитрам; конспект готов, нужна научная перепроверка | интервью не равно научному обзору |
| SRC-0010 | Даниэль Канеман, «Думай медленно… Решай быстро» | доступ подтверждён; структура и введение изучены; чтение продолжается | крупный объём и необходимость современной репликационной проверки |

## Исследовательское решение

Пакет пока не превращается в уроки. Сначала каждый источник проходит путь: доступ → проверка структуры → полное последовательное изучение → критическая перепроверка → решение о пригодности.

Книгу и видео Дорофеева нельзя автоматически считать полным курсом критического мышления. Они предварительно рассматриваются как источники о внимании, личной организации и проверке автоматических реакций. Для профессиональной компетенции бизнес-аналитика позже потребуются отдельные материалы по аргументации, логическим ошибкам, причинности, вероятности, проверке гипотез и качеству данных.
