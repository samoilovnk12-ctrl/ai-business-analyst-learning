# Lesson runtime

Use this workflow while delivering, reviewing, or continuing one lesson.

## Before the lesson

Read the mission, preferences, learning context, relevant learning records, glossary, source cards, and previous stopping point. Choose one bounded skill inside the learner's current zone of development.

## Standard lesson

A 90-minute lesson has three resumable parts:

1. **Understand:** work event, purpose, simple theory, and one worked example.
2. **Practice:** a different case, independent attempt, and progressively stronger hints.
3. **Apply:** a realistic artifact or decision, feedback, consequence, retrieval, and a concise reference note.

Adapt timing rather than padding the lesson.

## Language and feedback

Explain ordinary meaning first, then give the Russian professional term and English equivalent. Never test an undefined term.

For a free-form case, wait for `готово`. Then preserve the learner's wording, map it to the framework, mark areas covered/partial/missing, distinguish facts/assumptions/questions, ask only the nearest useful follow-up, and use a new case for reassessment after revealing the answer.

## Evidence and memory

Distinguish `covered`, `practiced`, `demonstrated`, and `transferred`. Only demonstrated or transferred knowledge can raise the assumed starting level or create a learning record. Add glossary terms only after correct use.
